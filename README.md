# Zunayra AI 🤖

**Zunayra AI** is a personal AI chatbot and assistant built to provide more personalized and continuous conversations through **long-term memory**.

The main idea behind Zunayra is simple: instead of treating every conversation as a completely new interaction, the assistant can save useful information in a **JSON-based memory system** and retrieve relevant memories during future conversations.

### ✨ Features

* 💬 Natural conversational AI
* 🧠 **Long-term memory using JSON**
* 🔎 Retrieval of relevant information from stored memories
* 👤 Personalized responses based on previous conversations
* 🗂️ Structured memory storage and management
* 🌐 Web search for information that may require up-to-date knowledge
* ⚡ Powered by **Qwen 4B**
* 🔄 Maintains conversational context while interacting with the user

### 🧠 How It Works

Zunayra follows a simple memory-based workflow:

**User → Conversation → Memory Extraction → JSON Storage → Memory Retrieval → AI Response**

Important information from conversations can be stored in a structured JSON memory file. When a new conversation takes place, Zunayra can retrieve relevant memories and provide them to the language model as additional context.

### 🛠️ Technology

* **Python**
* **Qwen 4B**
* **JSON-based Memory System**
* Large Language Models (LLMs)
* Web Search
* Conversational Context Management

### 🎯 Project Goal

The goal of Zunayra AI is to explore how a personal AI assistant can become more useful over time by developing a persistent memory of its interactions with a user.

Rather than simply building another chatbot, Zunayra is an experiment toward creating an AI assistant that can **remember, understand context, and provide increasingly personalized interactions**.
